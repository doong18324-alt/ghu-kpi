# 구글 스프레드시트 연동 설치 (처음 한 번, 약 5분)

대시보드의 "등록" 버튼을 누르면 값이 이 스프레드시트에 바로 저장되게 만드는 설정입니다.

1. **스프레드시트 만들기**
   - 학교 구글 계정으로 새 스프레드시트를 만듭니다. 이름 예: GHU 성과지표 등록
2. **스크립트 붙여넣기**
   - 메뉴에서 확장 프로그램 → Apps Script를 엽니다.
   - 기본으로 들어 있는 코드를 지우고, 이 폴더의 `Code.gs` 내용을 통째로 붙여 넣은 뒤 저장합니다.
3. **처음 실행 (관리자 키 만들기)**
   - 위쪽 함수 목록에서 `setup`을 고르고 실행합니다.
   - 권한 요청이 뜨면 허용합니다.
   - 실행 로그에 나오는 "관리자 키"를 적어 둡니다. 관리자 화면에서 시트 값을 불러올 때 씁니다.
   - 키를 바꾸려면 프로젝트 설정 → 스크립트 속성에서 `ADMIN_KEY` 값을 고칩니다.
4. **웹 앱으로 배포**
   - 배포 → 새 배포 → 유형 "웹 앱"을 고릅니다.
   - 실행 사용자는 "나", 액세스 권한은 "모든 사용자"로 정합니다.
   - 배포 후 나오는 웹 앱 URL(`https://script.google.com/macros/s/…/exec`)을 복사합니다.
5. **대시보드에 주소 넣기**
   - 저장소의 `config.js`를 열어 `window.KPI_SHEET_URL = '...'` 따옴표 안에 4번 주소를 넣고 저장합니다.
   - 1~2분 뒤 대시보드에 반영됩니다.

## 동작 방식
- 부서가 "등록"을 누르면 "등록" 시트에 한 값당 한 줄이 쌓입니다. 열은 등록 시각, 등록 번호, 부서, 작성자, 지표코드, 지표명, 연도, 구분, 값, 단위 순서입니다.
- 같은 값을 고쳐 다시 등록하면 새 줄이 추가되고 이전 줄은 남습니다. 관리자 화면에서는 서로 다른 값이 "값 조정"에 표시됩니다.
- 관리자 화면 → "스프레드시트에서 불러오기"에 관리자 키를 넣으면 시트 값을 가져옵니다. 키가 없으면 시트 내용을 읽을 수 없습니다.

## 주의
- "모든 사용자" 배포라 주소를 아는 사람은 값을 **쓸 수는** 있습니다. 주소는 학내에만 공유하고, 이상한 줄이 생기면 시트에서 지우면 됩니다. 읽기는 관리자 키가 있어야만 됩니다.
- `Code.gs`를 고친 뒤에는 배포 → 배포 관리 → 수정 → 새 버전으로 다시 배포해야 반영됩니다. 이때 주소는 그대로 유지됩니다.
